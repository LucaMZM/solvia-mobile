# Security

Solvía is a portfolio repository. Please do not post suspected secrets,
credentials or exploitable vulnerabilities in a public issue or pull request.

If GitHub private vulnerability reporting is enabled for this repository,
use it to share a minimal reproduction and affected version. Otherwise,
contact the maintainer through a private channel listed on the public
GitHub profile. Do not include live credentials in a report.

There is no paid weather-service account or remote push backend configured
in this source tree. `EXPO_PUBLIC_*` variables are public in the app bundle.
